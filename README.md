# Drilldown

The Drilldown Package provides an easy-to-use solution for creating animated, hierarchical menus using the GreenSock Animation Platform (GSAP). It allows for smooth transitions between menu levels with configurable options for customization and callbacks for advanced integrations.

## Features

- **Dynamic Hierarchical Menus**: Easily create multi-level drilldown menus to efficiently manage complex site navigation structures.
- **GSAP Animations**: Utilizes the GreenSock Animation Platform (GSAP) to provide smooth, high-performance transitions between menu levels.
- **Configurable Selectors**: Customize selectors for menu items, back buttons, submenus, and more to match your HTML structure.
- **Customizable Animation Callbacks**: Offers hooks for animation start and complete events at both child and parent levels, allowing for fine-tuned control over menu behavior.
- **Automatic Height Adjustment**: Features a ResizeObserver to automatically adjust the height of the drilldown menu, ensuring it matches the content for a seamless user experience.
- **Lifecycle Management**: Features methods for initializing and destroying drilldown instances, enabling proper setup and teardown of components to prevent memory leaks and ensure clean transitions between states.

## Usage

### JS initialisation

```ts
import { Drilldown, type DrilldownOptions } from '@numiko/drilldown';

const menuElement = document.getElementById('menu') as HTMLElement;
const options: DrilldownOptions = {
  backSelector: '[data-js-menu-back]',
  nextSelector: '[data-js-menu-next]',
  submenuSelector: '[data-js-menu-container]',
  itemSelector: '[data-js-menu-item]',
};

const menu = new Drilldown(menuElement, options);
menu.init();

```

## API

See [documentation](https://v1-2-1--numiko-drilldown.netlify.app/) for more detail on how to use the package.

### Customizing Tween Example
- `Drilldown(context, options = {})`: Initializes a new instance of the Drilldown class.
  - `context`: The HTMLElement to initialize the drilldown on.
  - `options`: Configuration options for the drilldown.

### Options

Customizable options and their defaults are as follows:

| Option | Description | Type | Default
| --- | --- | --- | --- |
| `backSelector` | Selector for back buttons. | `string` | `[data-js-menu-back]` |
| `nextSelector` | Selector for next buttons. | `string` | `[data-js-menu-next]` |
| `submenuSelector` | Selector for submenu containers. | `string` | `[data-js-menu-container]` |
| `itemSelector` | Selector for menu items. | `string` | `[data-js-menu-item]` |
| `childTweenOptions` | Configuration options to customize the tween for a child menu. See [Customizing Tween](#markdown-header-customizing-tween) | `object` | `null`
| `parentTweenOptions` | Configuration options to customize the tween for a parent menu. See [Customizing Tween](#markdown-header-customizing-tween) | `object` | `null`

#### Customizing Tween

Both the `childTweenOptions` and `parentTweenOptions` objects take the same customization options listed below.

| Option | Description | Type | Default
| --- | --- | --- | --- |
| `outDuration` | The tween duration when animating the current menu out | `number`  | `0.2`
| `outEase` | The tween ease when animating the current menu out | `string`  | `'power1.out'`
| `outStagger` | The tween stagger when animating the current menu out | `number` | `0` |
| `inDuration` | The tween duration when animating the new menu in | `number` | `0.2` |
| `inEase` | The tween ease when animating the new menu in | `string` | `'power1.out'` |
| `inStagger` | The tween stagger when animating the new menu in | `number` | `0.1` |
| `heightDuration` | The tween duration when animating the height of the drilldown menu | `number` | `0.3` |
| `heightEase` | The tween ease when animating the height of the drilldown menu | `string` | `'power1.out'` |
| `onStart` | Function to be called when the animation starts | `function` | `null` |
| `onComplete` | Function to be called when the animation completes | `function` | `null` |

#### Example
```ts
import { Drilldown } from '@numiko/drilldown';

const drilldownInstance = new Drilldown(context, {
  // tween specific options
  childTweenOptions: {
    outDuration: 0.2,
    outEase: 'power1.out',
    outStagger: 0,
    inDuration: 0.2,
    inEase: 'power1.out',
    inStagger: 0.1,
    heightDuration: 0.3,
    heightEase: 'power1.out',
    onStart: () => {
      console.log('current menu exiting');
    },
    onComplete: () => {
      console.log('child menu entered');
    }
  },
  parentTweenOptions: {
    outDuration: 0.2,
    outEase: 'power1.out',
    outStagger: 0,
    inDuration: 0.2,
    inEase: 'power1.out',
    inStagger: 0.1,
    heightDuration: 0.3,
    heightEase: 'power1.out',
    onStart: () => {
      console.log('current menu exiting');
    },
    onComplete: () => {
      console.log('parent menu entered');
    }
  }
});
```
